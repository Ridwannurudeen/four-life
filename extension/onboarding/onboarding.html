Certified vs Radar Estimate: a Certified tier is only issued when the agent has full on-chain measurement (buy/sell events, whale distribution, holder velocity). Tokens visible only via public ranking get a Radar Estimate with a distinct version string and explicit "heuristic only" banner. The pill, the modal, and the Chrome notifications all discriminate — no heuristic gets labeled as Certified.

3

Star tokens → Chrome alerts on tier changes

Click ★ Watch on any token's panel. When its tier transitions (healthy → at_risk, or radar_estimate → certified upgrade), a native Chrome notification fires. Click it to open the token's full evidence page.

Permissions we ask for: activeTab storage alarms notifications — no tracking, no analytics, no auth. Watchlist syncs across devices via chrome.storage.sync.
