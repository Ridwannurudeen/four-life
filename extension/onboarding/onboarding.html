Deterministic trust grading, wherever you browse BNB Chain tokens.

The extension injects a FOUR-LIFE Certified badge onto every four.meme, BscScan, PancakeSwap, and DEXScreener token page. Every tier ships with a full rule trace, contract-safety audit, creator reputation, history sparkline, and live on-chain attestation evidence — no black-box verdicts.

2

Visit any BNB Chain token page → the pill appears

A tier-colored pill lands in the top-right. At-risk pills pulse red so a honeypot reads structurally different from a safe token at a glance — matches the Pocket Universe / Rabby red-yellow-green hazard convention. Pair URLs on DEXScreener are auto-resolved to their base token before grading.

four.meme / $AUNT BscScan / $AUNT PancakeSwap / $AUNT DEXScreener / any BSC pair

Certified vs Radar Estimate: a Certified tier is only issued when the agent has full on-chain measurement (buy/sell events, whale distribution, holder velocity). Tokens visible only via public ranking get a Radar Estimate with a distinct version string and explicit "heuristic only" banner. The pill, modal, and Chrome notifications all discriminate — no heuristic gets labeled as Certified.

3

Click the pill → a deep inspection panel slides in

Every tier verdict is backed by eight live-fetched sections:

  • Animated health-score ring (0–100, tier-coloured arc)
  • Rule trace cards — hover the ℹ icon for plain-english explanation of each threshold
  • Contract-safety checklist — BscScan verified / mint / blacklist / pause / proxy / ownership renounced
  • Deployer reputation — launches tracked, graduations, grad-rate, trust tier
  • Snapshot-history sparkline — curve progress over time + tier-transition dot strip
  • On-chain attestation — live DGrid + MYX Merkle-root transactions, linked to BscScan
  • Freshness indicator — "Grade updated 23s ago" ticker, turns yellow past 60s
  • Severity-coded risk evidence with SVG warning icons

Two ways to go bigger: click Full page ↗ in the header to open the token's analysis as a real browser tab (bookmarkable, shareable), or Expand to widen the drawer to 1100px.

4

Firewall mode on at-risk tokens

Click Swap ↗ on an at-risk token and FOUR-LIFE blocks the route. A red block modal surfaces the top 2–3 critical evidence lines with a Cancel — stay safe primary button and a muted Override anyway secondary. The destructive navigation only happens if you explicitly override. This is the single feature that turns FOUR-LIFE from a dashboard into a safety product.

Separately, click ★ Watch on any panel to subscribe for Chrome notifications on tier transitions. When the token moves (healthy → at_risk, or radar_estimate → certified upgrade), a native alert fires. Click it to land on the token's full evidence page.

5

Right-click any address anywhere → grade it

Highlight a 0x… address on any webpage (Twitter, Telegram, Discord web, email), right-click → Grade "0x…" with FOUR-LIFE. The full rule trace opens in a new tab. Works on every site, not just the four we inject into.

The extension honours prefers-reduced-motion — ambient pulses and the at_risk alert animation disable themselves when the OS setting is on.

Permissions we ask for: activeTab storage alarms notifications contextMenus — no tracking, no analytics, no auth. Watchlist syncs across devices via chrome.storage.sync. All API calls go directly to four-life.gudman.xyz.
